# 004. 모델 실험 및 오류 분석

**프로젝트:** 온라인 쇼핑 구매 여부 예측 (PyTorch 신경망 분류)
**작성 범위:** CP-04~CP-08
**근거:** `code/02_classification_online_shopping.ipynb`의 코드와 실행 결과

> 모델별 비교 결과와 오류 분석에서 관찰한 내용을 기록한다. 최종 모델 선택 근거는 `adr.md`의 의사결정 ④에 정리한다.

## 1. 모델 평가 기준 (CP-04)

구매 여부를 맞히는 모델이 필요했다. 먼저 별다른 학습 없이도 얻을 수 있는 기준 점수와 간단한 분류 모델의 성능을 확인하고, 그 결과를 바탕으로 개선할 부분을 정하기로 했다.

- **양성 클래스:** 구매 (`Revenue=1`).
- **주 평가 지표:** 구매 클래스 F1. 구매라고 예측한 결과의 정확성과 실제 구매를 찾아낸 비율을 함께 본다.
- **보조 지표:** Accuracy, Precision, Recall과 혼동행렬의 FP, FN. FP는 미구매를 구매로 잘못 예측한 건수, FN은 실제 구매를 놓친 건수다.
- **비교 방법:** Train으로 전처리와 모델을 학습하고 Validation에서 설정을 비교했다. 기본 MLP-B의 Test를 확인한 뒤 가중치 절반 모델도 같은 Test에서 평가하고 최종 선택했다.

## 2. 기준 모델과 설정 비교 (CP-04)

첫 비교에서는 모든 방문을 미구매로 예측하는 DummyClassifier와 로지스틱 회귀를 학습했다. 구매 비율이 낮기 때문에 정확도와 함께 구매를 실제로 찾아낸 정도를 확인했다.

| 모델과 설정 | Train F1 | Validation Accuracy | Validation Precision | Validation Recall | Validation F1 |
| --- | ---: | ---: | ---: | ---: | ---: |
| DummyClassifier | 0.000 | 0.845 | 0.000 | 0.000 | 0.000 |
| LogisticRegression 기본 설정 | 0.505 | 0.882 | 0.734 | 0.367 | 0.490 |

- **기준 모델:** DummyClassifier는 모든 세션을 미구매로 예측해 정확도 84.5%를 기록했지만, 구매를 한 건도 찾지 못해 구매 F1은 0이다.
- **기본 로지스틱 회귀:** Validation의 실제 구매 286건 중 105건을 찾고 181건을 놓쳤다. 미구매 1,564건 중 38건을 구매로 잘못 예측했다.
- **설정 변경:** 구매를 더 잘 찾을 수 있는지 `C` 0.1, 1, 10과 클래스 가중치 기본값, `balanced`, 임계값 0.3, 0.5, 0.7의 18개 조합을 비교했다. `C`와 가중치를 바꿀 때 다시 학습하고 임계값을 바꿀 때는 예측 기준만 바꿨다.

| 로지스틱 회귀 설정 | Precision | Recall | F1 | FP | FN |
| --- | ---: | ---: | ---: | ---: | ---: |
| 기본: `C=1`, 기본 가중치, 임계값 0.5 | 0.734 | 0.367 | 0.490 | 38 | 181 |
| 비교 중 F1 최고: `C=0.1`, `balanced`, 임계값 0.7 | 0.700 | 0.563 | 0.624 | 69 | 125 |

**분석:** 기본 로지스틱 회귀는 구매 181건을 놓쳤다. 규제, 클래스 가중치, 임계값을 바꿔보니 가장 높은 F1을 기록한 조합은 구매 56건을 더 찾았다. 대신 미구매를 구매로 잘못 예측한 경우도 31건 늘었다. 하나의 설정이 모든 오류를 동시에 줄이지는 않았고, 같은 Validation에서 여러 설정을 비교했다는 점을 고려해 다음 모델과도 비교했다.

## 3. MLP 학습과 가중치 실험 (CP-05~CP-06)

로지스틱 회귀를 조정한 뒤에는 신경망도 비교했다. 먼저 구매 가중치를 주지 않은 MLP-A를 학습해 기준을 만들고, 구매 사례가 적다는 점을 반영해 손실에 가중치를 준 MLP-B를 학습했다. 두 모델은 같은 구조를 사용했다.

- **공통 구조:** 입력 73개 → 은닉층 64개 → 은닉층 32개 → 출력 1개. ReLU, Dropout 0.1, Adam, 학습률 0.001, 배치 크기 256을 사용했다.
- **MLP-A:** 구매 가중치 없이 학습했다. 25에포크 중 25번째의 Validation F1이 가장 높았다.
- **MLP-B:** 구매 사례를 더 잘 찾도록 가중 손실을 사용했다. Train의 미구매 7,294건을 구매 1,336건으로 나눈 약 5.460을 가중치로 적용했고, 17번째 에포크의 Validation F1이 가장 높았다.

| 모델 | Train F1 | Validation Precision | Validation Recall | Validation F1 | FP | FN |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| MLP-A, 가중치 없음 | 0.709 | 0.717 | 0.566 | 0.633 | 64 | 124 |
| MLP-B, 가중치 5.460 | 0.692 | 0.575 | 0.734 | 0.645 | 155 | 76 |
| 가중치 절반, 약 2.730 | 실습 결과 미표시 | 0.604 | 0.720 | 0.657 | 135 | 80 |

**분석:** MLP-B는 A보다 구매를 48건 더 찾았지만 미구매를 구매로 잘못 예측한 경우도 91건 늘었다. 가중치를 절반으로 낮춘 모델은 B보다 FP가 20건 적고 FN이 4건 많았으며 F1이 0.012 높았다. 가중치 절반 모델의 Train F1은 추가 실험표에서 출력하지 않아 기재하지 않았다.

**가중치 추가 실험:** 클래스 비율로 계산한 5.460이 이번 데이터에서도 적절한지 확인하려고 기본 손실, 가중치 2, 클래스 비율의 절반, 클래스 비율, 비율의 2배를 비교했다. 모델별로 임계값 0.5에서 Validation F1이 최고인 에포크를 선택한 뒤 임계값 0.3, 0.5, 0.7을 적용했다. 임계값마다 에포크를 새로 선택한 실험은 아니다. 가중치 절반은 16에포크에서 F1 0.657로 비교한 15개 조합 중 가장 높았다.

## 4. 예측 오류와 추가 검증 (CP-06~CP-07)

| 모델 | 임계값 | Precision | Recall | F1 | FP | FN |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| MLP-A | 0.3 | 0.608 | 0.678 | 0.641 | 125 | 92 |
| MLP-A | 0.5 | 0.717 | 0.566 | 0.633 | 64 | 124 |
| MLP-A | 0.7 | 0.835 | 0.353 | 0.496 | 20 | 185 |
| MLP-B | 0.3 | 0.459 | 0.839 | 0.593 | 283 | 46 |
| MLP-B | 0.5 | 0.575 | 0.734 | 0.645 | 155 | 76 |
| MLP-B | 0.7 | 0.639 | 0.612 | 0.625 | 99 | 111 |

**분석:** 두 모델에서 임계값을 낮추면 구매로 판정하는 건수가 늘어 FP는 증가하고 FN은 감소했다. 기본 A/B 여섯 조합 중에는 B의 임계값 0.5가 가장 높았으며, 추가 가중치 실험까지 고려해 이후 가중치 절반 모델을 선택했다.

### 추가 검증: 중복 행과 다섯 분할 비교

가중치 절반의 F1이 높았지만, 한 번 나눈 Validation에서만 나온 결과였다. 데이터를 다르게 나누어도 같은 경향이 나오는지 확인했다. 분할 전에 같은 값의 행을 유지했으므로 그 행이 학습과 검증 양쪽에 있는지도 함께 살펴봤다.

- **기존 분할의 중복:** Train과 Validation에 같은 값의 행이 29종류 있었고 각각 48행과 32행이었다. 기존 MLP-B에서 겹친 Validation 32행을 제외하자 구매 F1은 0.645로 같았고 정확도는 0.875에서 0.873으로 낮아졌다. 제외된 32행은 모두 미구매를 맞힌 사례다. 중복을 제거해 재학습한 실험은 아니다.
- **다섯 분할:** Test를 제외한 10,480행을 같은 입력과 정답을 가진 행끼리 묶어서 나눴다. 각 분할에서 Train만으로 전처리를 학습하고, 두 모델의 구조와 시드 42, 17에포크, 임계값 0.5를 같게 두고 가중치만 비교했다.

| 모델 | 평균 F1 | 평균 Precision | 평균 Recall | 평균 FP | 평균 FN |
| --- | ---: | ---: | ---: | ---: | ---: |
| 기존 MLP-B | 0.627 | 0.503 | 0.832 | 267.2 | 54.6 |
| 가중치 절반 | 0.659 | 0.580 | 0.763 | 179.4 | 77.0 |

**해석:** 가중치 절반 모델의 F1이 다섯 분할 모두 높았지만, 놓친 구매도 많았다. 학습 데이터가 분할 간에 겹치고 17에포크는 앞선 Validation에서 정한 값이다. 동일한 값이 반드시 같은 방문이라는 뜻은 아니며, 실행 환경에 따라 일부 수치는 조금 달라질 수 있다.

## 5. 최종 모델과 Test 평가 (CP-08)

기본 MLP-A와 B만 비교했을 때는 B를 선택해 Test를 확인했다. 이후 가중치 절반 모델이 Validation 추가 실험과 다섯 분할 비교에서 더 높은 F1을 기록한 것을 확인하고, 같은 Test에서도 두 모델의 결과를 비교했다. 구매를 놓치는 건수는 늘었지만 이번 프로젝트의 주 지표인 F1이 높아 가중치 절반 모델을 최종 선택했다.

- **최종 설정:** MLP-B 구조에서 구매 가중치를 Train + Validation의 미구매 / 구매 비율의 절반인 약 2.731로 적용했다. 임계값은 0.5, 학습은 16에포크다. 16에포크는 앞선 Validation 실험에서 선택했다.
- **재학습 데이터:** Train + Validation 10,480행. 범주 목록과 표준화 기준을 다시 학습해 17개 입력을 74개 열로 변환했다. Test에는 같은 기준으로 변환만 적용했다.

| 모델 | Test Accuracy | Test Precision | Test Recall | Test F1 | FP | FN |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 기존 MLP-B, 17에포크 | 0.858 | 0.526 | 0.843 | 0.648 | 217 | 45 |
| 최종 가중치 절반, 16에포크 | 0.884 | 0.603 | 0.724 | 0.658 | 136 | 79 |

**해석:** 최종 모델은 실제 구매 286건 중 207건을 찾고 79건을 놓쳤다. 기존 모델보다 F1은 0.010 높고 FP는 81건 적지만 FN은 34건 많았다. F1을 우선하는 이번 프로젝트의 기준으로 가중치 절반 모델을 선택했다.

- **저장 및 재로딩:** `results/02_final_classifier.joblib`에 전처리와 모델 가중치를, `results/02_model_config.json`에 설정을 저장했다. 다시 불러온 모델의 Test 1,850건 예측이 저장 전과 일치했다.
- **단일 입력 예측:** 첫 번째 Test 세션의 출력 점수는 0.0047로, 임계값 0.5보다 낮아 미구매로 예측했다. 실제 정답도 미구매다. 가중 손실 모델의 출력 점수가 실제 구매 확률로 정확히 보정되었는지는 확인하지 않았다.
- **평가 이력:** 기존 MLP-B의 Test를 먼저 확인한 뒤 가중치 절반 모델도 같은 Test로 비교하고 최종 선택했다. Test F1 0.658은 이번 데이터의 결과이며 다른 데이터에서도 유지되는지는 확인하지 않았다. Train + Validation과 Test 사이에 같은 값의 행 15종류가 있었고 Test 20행이 해당했다.

## 6. 실험 요약

- **주요 결과:** 로지스틱 회귀 설정 조정으로 Validation F1은 0.490에서 0.624로 높아졌다. MLP 추가 가중치 실험에서는 가중치 절반이 0.657로 가장 높았고, 다섯 분할 평균도 기존 B의 0.627보다 높은 0.659였다.
- **남은 한계:** 하나의 Validation을 여러 설정 비교에 사용하고 Test도 반복 확인했다. `PageValues`를 포함한 입력이 방문 초기에 모두 사용 가능한지도 확인하지 않았다. 향후 새로운 데이터에서 일반화 성능을 확인할 필요가 있다.
