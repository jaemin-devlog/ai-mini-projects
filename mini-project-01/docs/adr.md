## 1일차 — 회귀 (공유자전거 대여 수요 예측)

### 의사결정 ① 입력 특성 선택 (CP-02)

**문제**

예측 시점에 사용할 수 없거나 누수가 발생할 수 있는 특성이 있습니다.

- **검토한 선택지:** 정답 구성 요소인 `casual`, `registered`의 포함 여부, 상관관계가 높은 `temp`, `atemp`의 사용 여부와 `windspeed`의 유지 여부를 검토했다.
- **CP-02의 기본 입력 선택:** 시간, 달력, 날씨 관련 기본 특성 12개(`season`, `yr`, `mnth`, `hr`, `holiday`, `weekday`, `workingday`, `weathersit`, `temp`, `atemp`, `hum`, `windspeed`)를 사용했다. 정답 `cnt`, 대여 후 집계값 `casual`, `registered`, 식별자 `instant`, 분할용 날짜 `dteday`는 입력에서 제외했다.
- **이후 변경:** CP-03에서 만든 `is_commute_hour`는 CP-07 검증 실험을 거쳐 최종 모델에서 제외했다.
- **선택 근거:** 모든 행에서 `casual + registered == cnt`가 성립하고 두 값은 대여 후에 알 수 있어 사용하면 정답 정보가 누출된다. `temp`와 `atemp`의 Train 상관계수는 0.992, `windspeed`와 `cnt`는 0.094였지만 상관계수만으로 특성을 제거하지 않고 둘 다 기본 입력에 유지했다.
- **한계 및 확인할 점:** 미래 날씨는 예보로 얻을 수 있다고 가정했으며, 실제 예보 오차의 영향은 확인하지 않았다. 높은 상관관계가 있는 두 온도 특성을 각각 제외했을 때의 성능도 별도 검증할 수 있다.

**분석 근거:** `01_regression_data_analysis.md`

### 의사결정 ② 최종 회귀 모델 선택 (CP-07)

**문제**

서로 다른 회귀 모델 및 설정 중 하나를 최종 모델로 선택해야 합니다.

- **비교한 모델과 설정**은 랜덤 포레스트(트리 200개, 깊이 제한 없음)와 선형 회귀다.
- **최종 모델**은 트리 200개, 깊이 제한 없는 랜덤 포레스트다. 시간대와 근무일 여부는 사용하고, 두 값을 합쳐 만든 출퇴근 특성은 제외했다.
- **선택 근거**는 같은 검증 기간의 MAE다. 선형 회귀는 99.854대였고, 랜덤 포레스트에서 출퇴근 특성을 제외해 재학습하자 94.532대에서 86.194대로 줄었다.
- **검증 RMSE**도 출퇴근 특성을 빼고 재학습하자 142.248대에서 125.382대로 줄었다. 선형 회귀의 검증 RMSE는 124.008대였다.
- **추가 검증과 한계:** 기존 Validation에서 제외 모델은 24개 중 16개 시간대에서 MAE가 낮았지만 8시에는 높았다. Train 내부의 확장형 시간순 검증에서는 제외 모델이 3회 중 2회에서 낮았고, 평균 차이는 약 0.318대에 그쳤다. 기간별 결과가 달라 일반적인 우위를 단정하기 어렵다.

**분석 근거:** `01_regression_model_analysis.md`

## 2일차 — 분류 (온라인 쇼핑 구매 여부 예측, PyTorch MLP)

### 의사결정 ③ 평가 지표 선택 (CP-04)

**문제**

구매 세션이 전체의 약 15%인 불균형 데이터에서 구매 예측 성능을 판단해야 한다.

- **검토한 지표:** Accuracy, 구매 클래스 Precision, Recall, F1과 FP, FN.
- **선택:** 구매 클래스 F1을 우선하고 나머지 지표와 오류 건수도 함께 확인한다.
- **근거:** Validation에서 모든 방문을 미구매로 예측한 DummyClassifier의 Accuracy는 0.845였지만 구매 F1은 0이었다. 기본 LogisticRegression도 실제 구매 286건 중 181건을 놓쳤다.
- **한계:** F1은 FP와 FN의 실제 비용 차이를 직접 반영하지 않는다. 실제 구매를 놓치는 비용이 크다면 Recall과 FN을 별도로 고려해야 한다.

**분석 근거:** `02_classification_data_analysis.md`, `02_classification_model_analysis.md`

### 의사결정 ④ 최종 분류 모델 선택 (CP-06~CP-08)

**문제**

구매 클래스 가중치와 임계값에 따라 정밀도와 재현율이 달라지므로 프로젝트의 평가 기준에 맞는 모델을 선택해야 한다.

- **비교한 설정:** 기본 MLP-A, 클래스 비율을 가중치로 사용한 MLP-B, 가중치를 절반으로 줄인 모델과 각 설정의 임계값을 비교했다.
- **최종 모델:** MLP-B와 같은 구조에 구매 가중치를 학습 데이터의 클래스 비율 절반으로 적용했다. Train + Validation에서 가중치는 약 2.731이며 임계값 0.5, 16에포크로 재학습했다.
- **선택 근거:** 기존 Validation F1이 0.657로 기본 MLP-B의 0.645보다 높았다. 같은 값의 행을 묶은 다섯 분할에서도 평균 F1이 0.659로 기존 B의 0.627보다 높았다.
- **오류의 차이:** Validation에서 가중치 절반 모델은 기본 B보다 FP가 20건 적었고 FN은 4건 많았다. F1을 우선했지만 실제 구매를 놓치는 비용이 큰 상황에는 이 차이를 고려해야 한다.
- **한계:** 이 Test는 이전에 확인하고 모델 비교에도 사용했다. 현재 선택의 근거는 Validation 결과이며, Test F1 0.658을 독립적인 새 데이터의 성능으로 볼 수 없다.

**분석 근거:** `02_classification_model_analysis.md`
