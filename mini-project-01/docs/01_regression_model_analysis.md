# 002. 모델 실험 및 오류 분석

**프로젝트:** 공유자전거 대여 수요 예측 (회귀)  
**작성 범위:** CP-04~CP-08  
**근거:** `code/01_regression_bike_demand.ipynb`의 코드와 실행 결과

> 모델별 비교 결과와 오류 분석에서 관찰한 내용을 기록한다. 최종 모델 선택 근거는 `adr.md`의 의사결정 ②에 정리한다.

## 1. 모델 평가 기준 (CP-04)

- **주 평가 지표:** MAE. 시간당 예측 대여량이 실제와 평균적으로 몇 대 차이 나는지 직접 해석할 수 있다.
- **보조 지표:** 큰 오차에 더 민감한 RMSE와 평균 예측을 기준으로 비교하는 R².
- **모델 비교 데이터:** Train으로 학습한 모델을 Validation에서 비교했다. 최종 모델을 Test에서 평가했으며, 실습 기록에는 이전 모델의 Test 확인 이력도 남아 있다.

## 2. 모델별 실험 결과 (CP-04~CP-06)

같은 Train, Validation 분할과 출퇴근 특성을 포함한 입력으로 실험했다. 아래 표에는 랜덤 포레스트 9개 조합 중 대표 설정만 표시한다. MAE는 낮을수록 좋다.

| 모델과 설정 | Train MAE | Validation MAE | Validation RMSE |
| --- | ---: | ---: | ---: |
| DummyRegressor (`mean`) | 119.572 | 194.109 | 253.892 |
| LinearRegression | 55.334 | 99.854 | 124.008 |
| Decision Tree (깊이 3) | 82.785 | 158.976 | 194.181 |
| Decision Tree (깊이 6) | 62.340 | 120.455 | 160.465 |
| Decision Tree (깊이 12) | 32.297 | 107.288 | 161.604 |
| Decision Tree (깊이 15) | 21.628 | 101.432 | 157.598 |
| Decision Tree (깊이 20) | 9.610 | 110.955 | 174.651 |
| Decision Tree (깊이 제한 없음) | 0.012 | 99.455 | 153.082 |
| Random Forest (트리 50개, 깊이 20) | 14.996 | 95.074 | 142.015 |
| Random Forest (트리 200개, 깊이 20) | 14.773 | 94.758 | 142.560 |
| Random Forest (트리 200개, 깊이 제한 없음) | 10.217 | 94.532 | 142.248 |

**실험에서 발견한 점**

- 선형 회귀의 Validation MAE는 기준 모델보다 94.255대 낮았다. Train과 Validation의 MAE는 각각 55.334대, 99.854대로 차이가 났지만 두 기간의 수요 패턴도 다르므로 이 차이만으로 과대적합을 확정하지 않는다.
- 결정 트리는 깊이 3에서 15로 늘릴 때 검증 MAE가 158.976대에서 101.432대로 줄었다. 깊이 20에서는 Train MAE가 더 낮아졌지만 검증 MAE는 110.955대로 증가했다. 깊이 제한 없는 설정의 검증 MAE는 99.455대로 실험한 트리 중 가장 낮았다.
- 랜덤 포레스트는 트리 50, 100, 200개와 깊이 15, 20, 제한 없음의 9개 조합을 비교했다. 깊이 20에서 트리를 50 → 100 → 200개로 바꿨을 때 검증 MAE는 95.074 → 95.225 → 94.758대로 꾸준히 감소하지는 않았다.
- 출퇴근 특성을 포함한 초기 비교에서는 트리 200개, 깊이 제한 없음의 랜덤 포레스트가 검증 MAE 94.532대로 가장 낮았다. 선형 회귀의 검증 RMSE는 124.008대로, 이 랜덤 포레스트의 142.248대보다 낮았다.

## 3. 예측 오류 분석과 추가 실험 (CP-07)

- **오류 분석 대상:** 랜덤 포레스트(200개, 깊이 제한 없음)와 선형 회귀. 각각 전체 검증 MAE와 RMSE가 낮은 모델을 비교했다. MAE 상위 두 설정은 랜덤 포레스트 200개, 깊이 제한 없음과 200개, 깊이 20이다.
- **실제값과 예측값 그래프:** 선형 회귀는 실제 대여량이 많은 구간에서 과소 예측하는 경향을 보였다. 랜덤 포레스트는 높은 대여량을 더 잘 따라갔지만, 실제 대여량이 적을 때 수백 대로 과대 예측한 사례도 있었다.
- **시간대별 오류:** 17시 MAE는 랜덤 포레스트 117.2대, 선형 회귀 195.8대였고, 3시에는 각각 172.7대와 99.5대였다. 0~6시에는 선형 회귀가, 8시와 17~19시에는 랜덤 포레스트가 더 낮은 오차를 보였다. 이 비교는 출퇴근 특성을 포함한 모델의 결과다.
- **특성 중요도:** 기존 랜덤 포레스트에서 Validation의 출퇴근 여부를 섞자 MAE가 평균 77.243대 늘었다. 시간대는 60.763대, 체감온도는 20.991대 늘었다. 출퇴근 여부와 시간대, 근무일 여부는 정보를 공유하므로 증가량을 단순히 합할 수 없다.

**출퇴근 특성 제외 실험:** 같은 설정의 랜덤 포레스트에서 `is_commute_hour`만 제외하고 다시 학습했다. Validation MAE는 **94.532 → 86.194대**, RMSE는 **142.248 → 125.382대**로 낮아졌다. 특성 중요도는 이미 학습한 모델의 입력을 섞은 결과이고, 제외 실험은 해당 특성 없이 모델을 다시 학습한 결과다. 이번 검증 기간의 비교를 근거로 최종 모델에서는 출퇴근 특성을 제외했다.

### 추가 검증: 시간대와 검증 기간에 따른 차이

- **기존 Validation의 시간대별 MAE:** 출퇴근 특성을 제외한 모델은 24개 시간대 중 16개에서 오차가 낮았다. 3시는 172.69대에서 134.73대로 낮아졌지만 8시는 121.32대에서 170.73대로 높아졌다. 이는 Train으로 학습한 두 설정의 비교다.
- **Train 내부의 확장형 시간순 검증:** 3회차의 포함/제외 MAE는 각각 76.136/75.932대, 53.968/52.404대, 75.555/76.368대였다. 제외 모델이 2회에서 낮았지만 1회에서는 높았다. 3회 단순 평균은 포함 68.553대, 제외 68.235대로 약 0.318대 차이였다.
- **해석:** 기존 Validation의 약 8.338대 개선은 모든 기간에 같은 크기로 나타나지 않았다. 학습 기간이 겹치는 세 번의 검증만으로 어느 설정이 항상 우월하다고 단정할 수 없다. 기존 Validation과 Test는 이 추가 검증에서 사용하지 않았다.

## 4. 최종 모델과 Test 평가 (CP-08)

- **최종 설정:** `RandomForestRegressor(n_estimators=200, max_depth=None, random_state=42, n_jobs=-1)`. 출퇴근 특성을 제외한 12개 기본 입력 특성을 사용했다.
- **재학습 데이터:** Train과 Validation을 합친 14,755행.
- **Test 결과:** MAE **54.118대**, RMSE **81.485대**, R² **0.856**.
- **저장 및 확인:** 전처리와 모델을 포함한 Pipeline을 `results/01_final_model.joblib`에 저장했다. Test 앞 100건의 저장 전후 예측이 허용 오차 안에서 일치했다(`True`).
- **단일 입력 예측:** 실습 파일의 10월 근무일 18시, 기온 20°C 예시에서 예상 대여량은 **653대**였다. 나머지 입력값도 해당 예시의 조건을 사용했다.

**해석:** 최종 모델의 Test 예측은 실제 대여량과 한 시간당 평균 약 54.1대 차이 났다. Validation과 Test는 서로 다른 기간이며, 최종 모델은 Train과 Validation을 합쳐 재학습했으므로 두 점수를 단순 개선율로 비교하지 않는다. 실습 파일에는 이전에 확인한 출퇴근 특성 포함 모델의 Test MAE 58.23대도 기록되어 있으나, 최종 입력 특성은 Validation 비교를 근거로 선택했다. Test 결과를 반복 확인한 이력은 최종 평가의 독립성을 해석할 때 고려한다.

## 5. 실험 요약

- **주요 결과:** 초기 실험에서 랜덤 포레스트 200개, 깊이 제한 없음의 Validation MAE가 가장 낮았고, 출퇴근 특성을 제외해 재학습하자 검증 MAE가 86.194대로 더 낮아졌다.
- **남은 한계:** 초기 오류 분석에서는 새벽과 퇴근 시간대에 모델별 오차 차이가 컸다. 추가 비교에서 특성 제외 효과는 시간대와 기간에 따라 달랐다. 세 검증 기간의 학습 데이터가 겹치므로 더 다양한 기간에서 안정성을 확인할 필요가 있다.
